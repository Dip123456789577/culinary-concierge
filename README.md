# Culinary Concierge

Build a **premium, production-quality restaurant website with an integrated AI restaurant chatbot**.

This website is being created as a **high-value commercial website for a professional restaurant client**, so the final result must NOT look like a basic template, student project, or generic AI-generated website.

The website should feel like it was designed and developed by a **premium luxury hospitality web-design agency**.

Prioritize:

* Premium visual design
* Professional branding
* Strong typography
* Excellent UX
* High-quality food imagery
* Smooth interactions
* Mobile responsiveness
* Clear conversion-focused CTAs
* Easy restaurant reservations
* Easy access to contact information
* A polished restaurant AI chatbot

---

# 1. BRAND & VISUAL STYLE

Create an elegant luxury restaurant identity.

Use a sophisticated color palette:

* Warm ivory / cream
* Deep charcoal
* Almost-black
* Dark brown
* Subtle champagne/gold accents
* White typography on dark sections

Do not use excessive bright colors.

The overall website should communicate:

**Luxury • Taste • Trust • Elegance • Hospitality**

Use large editorial-style typography combined with clean modern sans-serif typography.

Use generous whitespace and excellent visual hierarchy.

Avoid:

* Cheap-looking gradients
* Excessive rounded cards
* Excessive animations
* Cluttered layouts
* Generic dashboard-style UI
* Overuse of gold
* Poor contrast
* Tiny text

## Development

You need Node.js (or Bun) to run this project locally.

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```

The dev server starts at `http://localhost:8080`.
